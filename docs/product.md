# Product definition

## User and goal

The learner is Yuelin, currently working around grade 3-4 English. The parent
selects lessons and reviews evidence. The product succeeds when Yuelin speaks
more willingly, stays interested, and gradually improves accuracy.

## Core learner flow

1. Select one three-stage lesson.
2. Hear a short teacher prompt.
3. Answer naturally, ask a relevant role question, request help, or briefly
   talk about something related.
4. Receive a concise, warm response.
5. Continue the same task unless its semantic goal is complete.
6. Enter pronunciation assessment only after an explicit repeat instruction.
7. Finish with evidence-based encouragement rather than technical overload.

## Core parent flow

1. Upload and validate a lesson.
2. See independent completion grades per stage.
3. Review real learner sentences, gentle recasts, and detailed pronunciation
   metrics from explicit repeat tasks.
4. Select a small review pack for day 1, 3, and 7 practice.

## Priority

- P0: reliable natural turn management and state preservation.
- P0: honest pronunciation gating and evidence-based records.
- P1: engaging lesson choices and age-appropriate task length.
- P1: PC/iPad-landscape usability.
- P2: streaming, VAD, cached TTS, and additional exercise types.

Fill-in-the-blank exercises are intentionally outside the current speaking
module scope.
